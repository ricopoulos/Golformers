## 🎯 Quick Start Guide

### Midjourney Parameters to Know:
- `--v 6.1` = Latest realistic model (best for logos, products)
- `--niji 6` = Anime/manga style (best for character art)
- `--ar 2:3` = Portrait card ratio
- `--ar 16:9` = Social media landscape
- `--style raw` = Less stylized, more control
- `--s 50` to `--s 1000` = Stylization level (50=minimal, 1000=maximum)

### Testing Strategy:
1. Run each prompt
2. Select 1-2 favorites
3. Use `Vary (Subtle)` or `Vary (Strong)` to refine
4. Upscale winners for final assets

## ADVANCED TIPS & VARIATIONS

### Character Consistency Tips:
1. **Save your favorite character prompts** - Once you find a Kai/Blaze/Luna/Torque you love, save that seed number
2. **Use `--sref` for style consistency** - Generate a style reference image first, then apply across all characters
3. **Character reference with `--cref`** - Lock in a character's face/look across multiple poses

### Testing Workflow:
```
1. Generate 4 variations of Prompt 3A (Kai full design)
2. Pick favorite → Upscale
3. Generate Prompt 3B (action portrait) using `--cref [Kai upscaled image URL]`
4. This ensures same Kai face/look across different poses
```

### Style Reference Example:
```
Generate this first:
"CRESTLINE brand style reference, anime collectible card game aesthetic, forest green and gold color palette, modern sports anime meets premium TCG art, visual style guide --niji 6 --ar 16:9"

Then add to all future prompts:
--sref [style reference image URL]
```
